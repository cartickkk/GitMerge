# GitMerge 🚀
> *Zero merge conflicts. Complete teams.*

**GitMerge** is a full-stack teammate and squad-matching platform designed for hackathons and competitive events. Built to eliminate the friction of finding complementary teammates, GitMerge pairs solo developers and incomplete squads based on technical skill synergy, role balance (Frontend, Backend, UI/UX, AI/ML), and team capacity limits.

---

### ⚡ Key Features
* **Role & Skill Synergy Matching:** An algorithmic engine evaluates role gaps to ensure well-rounded squads (avoiding all-frontend or all-backend teams).
* **Live Dev Card Preview:** Real-time visual badge rendering for individual developer profiles and open squad listings.
* **Squad Creation & Bounty Hunting:** Post openings for missing roles with customized stack requirements and experience preferences.
* **Dual Directories:** Dedicated views for solo developers looking for teams and incomplete squads recruiting members.
* **Lightweight Data Durability:** Native file-handling persistence layer without heavy third-party database dependencies.

---

### 🛠️ Tech Stack & Architecture
* **Frontend:** Semantic HTML5, Modular CSS3 (custom high-contrast dark palette), and Vanilla JavaScript.
* **Backend Engine:** Modern C++ (Object-Oriented Programming, custom class hierarchies, data persistence via file streams).
* **Networking & API:** RESTful JSON endpoints bridged via lightweight C++ HTTP server.
